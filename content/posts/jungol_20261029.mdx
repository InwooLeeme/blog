## 코드 사용 방법

기존 풀이 글처럼 각 코드 블록의 `solve()`를 개인 템플릿에 하나씩 넣어 사용한다. 공통 헤더와 `Main()`, `main()`은 생략했다. `ri`, `po`, `vi`, `vl`, `vvi`, `vvl`, `vs`, `pii`, `F0R`, `FOR`, `each`, `all`, `chmax`, `bound`를 사용하며, `ll`은 `long long`이다.

`Main()`의 테스트 케이스 수는 기본값인 `t = 1`로 둔다. Fibonacci Freeze의 테스트 케이스 수, 비밀번호의 `0`, 단어 세기의 `END`는 각 `solve()` 안에서 처리한다. 단어 세기는 첫 입력부터 `getline`으로 읽으므로, 템플릿에서 별도의 테스트 케이스 수를 먼저 읽지 않는다.

Fibonacci Freeze는 십진수 문자열 덧셈을, Chess Metric은 답의 상한을 이용한 포화 덧셈을 사용한다. 별도의 큰 정수 라이브러리는 필요하지 않으며, 아래 코드는 GNU C++20 환경을 기준으로 한다.

## 1. 5931 — 숫자사각형4-1

[문제 원문](https://jungol.co.kr/problem/5931)

한 변의 길이 $N$이 주어지면 첫 행은 1, 두 번째 행은 2처럼 **행 번호를 그 행 전체에 출력**한다. $1 \le N \le 100$이며, 숫자 사이는 공백으로 구분한다.

### 출력값은 열 번호와 관계없다

바깥 반복문은 행을, 안쪽 반복문은 그 행에 출력할 숫자 개수를 담당한다. 숫자 사이에만 공백을 넣고 행이 끝나면 개행한다.

```cpp showLineNumbers
void solve(){
    int n; ri(n);
    FOR(r, 1, n + 1){
        F0R(c, n){
            if(c) cout << ' ';
            cout << r;
        }
        cout << '\n';
    }
}
```

$N^2$개의 값을 출력하므로 시간 복잡도는 $O(N^2)$, 추가 공간은 $O(1)$이다. 원문에서 `N = 3`인 예제는 각 행에 `1 1 1`, `2 2 2`, `3 3 3`을 출력한다.

## 2. 2096 — 분수크기 비교

[문제 원문](https://jungol.co.kr/problem/2096)

양의 정수 $a,b,c,d$가 주어질 때 $a/b$와 $c/d$를 비교한다. 앞의 분수가 크면 `1`, 같으면 `0`, 작으면 `-1`을 출력한다. 각 입력값은 10,000 이하이다.

### 나누지 않고 교차 곱하기

두 분모가 양수이므로 양변에 $bd$를 곱해도 부등호 방향은 유지된다. 따라서 $ad$와 $bc$를 비교하면 된다. 정수 나눗셈으로 소수 부분을 버리거나 실수 오차를 고려할 필요가 없다.

```cpp showLineNumbers
void solve(){
    ll a, b, c, d; ri(a, b, c, d);
    ll left = a * d, right = b * c;
    po((left > right) - (left < right));
}
```

불리언 값은 정수 식에서 참이면 1, 거짓이면 0으로 계산된다. 두 비교 결과의 차이가 필요한 출력값이다. 이 입력 범위에서는 곱도 `int`에 들어가지만, 코드에서는 곱셈 전부터 `ll`을 사용했다.

시간과 공간은 $O(1)$이다. 원문 예제 `3 4 5 6`에서는 $18 < 20$이므로 답은 `-1`이다.

## 3. 1000 — 두 정수 더하기 (A+B)

1 이상 1,000 이하인 두 정수를 입력받아 합을 출력한다. 입력은 두 정수 한 쌍이며 테스트 케이스 수는 주어지지 않는다.

```cpp showLineNumbers
void solve(){
    int a, b; ri(a, b);

}
```

최댓값은 2,000이므로 `int`로 충분하다. 시간과 공간은 $O(1)$이다. 원문 예제의 `1 2`는 `3`, `3 4`는 `7`이다.

## 4. 1691 — 비밀번호

[문제 원문](https://jungol.co.kr/problem/1691)

21억 이하의 정수를 입력받아 마지막 다섯 자리를 비밀번호로 사용한다. 다섯 자리 안에 같은 숫자가 있으면 사용할 수 없다. 사용할 수 있으면 **그 다섯 숫자를 오름차순으로 정렬해** 출력하고, 중복이 있으면 `Disable password!!`를 출력한다. `0`은 입력 종료 표식이다.

### 정렬은 각 비밀번호 안에서 한다

여러 입력값 전체를 정렬하는 문제가 아니다. 입력 하나마다 끝에서 다섯 자리를 꺼내고, 이 다섯 숫자를 정렬한다. 정렬한 뒤 이웃한 숫자가 같다면 중복이 있다.

다섯 자리를 문자열로 만들면 정렬 결과의 맨 앞에 오는 `0`도 그대로 출력할 수 있다. 추출은 `% 10`과 `/ 10`을 다섯 번 반복한다.

```cpp showLineNumbers
void solve(){
    ll n;
    while(cin >> n && n != 0){
        string s;
        F0R(i, 5){
            s += char('0' + n % 10);
            n /= 10;
        }
        sort(all(s));
        bool ok = true;
        FOR(i, 1, 5) if(s[i] == s[i - 1]) ok = false;
        if(ok) cout << s << '\n';
        else cout << "Disable password!!\n";
    }
}
```

예를 들어 `1397628`의 마지막 다섯 자리는 `97628`이므로 `26789`를 출력한다. `29762`는 숫자 2가 겹치므로 사용할 수 없다. 종료 표식 `0`은 검사하지 않는다.

입력 하나당 다섯 자리만 처리하므로 시간과 추가 공간은 $O(1)$이다. 입력이 $Q$개라면 전체 시간은 $O(Q)$이다.

## 5. 1511 — Fibonacci Freeze

[문제 원문](https://jungol.co.kr/problem/1511)

최대 1,000개의 테스트 케이스에 대해 $F_n$을 출력한다. $n$은 최대 5,000이며, $F_0=0$, $F_1=1$이다. 정올 원문은 **첫 줄에 테스트 케이스 수 $T$를 받는 형식**이므로 이를 먼저 읽는다.

### 큰 정수로 한 번만 계산하기

점화식은 $F_n=F_{n-1}+F_{n-2}$지만, 5,000번째 항은 일반적인 64비트 정수에 들어가지 않는다. 값을 십진수 문자열로 저장하고, 질의 중 가장 큰 인덱스까지만 전처리한다. 두 문자열을 뒤에서부터 더하면서 올림을 전달하면 자릿수 제한 없이 계산할 수 있다.

```cpp showLineNumbers
void solve(){
    int t; ri(t);
    vi q(t); ri(q);
    int limit = 1;
    each(n, q) chmax(limit, n);
    auto add = [](const string& a, const string& b){
        int i = (int)a.size() - 1, j = (int)b.size() - 1, carry = 0;
        string res;
        while(i >= 0 || j >= 0 || carry){
            int sum = carry;
            if(i >= 0) sum += a[i--] - '0';
            if(j >= 0) sum += b[j--] - '0';
            res += char('0' + sum % 10);
            carry = sum / 10;
        }
        reverse(all(res));
        return res;
    };
    vs fib(limit + 1);
    fib[0] = "0";
    fib[1] = "1";
    FOR(i, 2, limit + 1) fib[i] = add(fib[i - 1], fib[i - 2]);
    each(n, q) cout << fib[n] << '\n';
}
```

같은 인덱스가 여러 번 나와도 다시 계산하지 않는다. `n = 0`인 경우에도 초기값을 그대로 출력한다. 원문 예제의 인덱스 `5`, `7`, `11`에 대한 결과는 각각 `5`, `13`, `89`다.

최대 인덱스를 $L$이라 하면 큰 정수 덧셈은 $O(L)$번 수행한다. 다만 큰 정수 연산은 상수 시간이 아니다. $F_i$의 비트 수가 $\Theta(i)$이므로 전처리의 비트 연산량과 저장 공간은 각각 $O(L^2)$이다. 질의 저장에는 추가로 $O(T)$ 공간이 필요하고, 출력에도 결과의 자릿수에 비례하는 시간이 든다.

## 6. 1516 — 단어 세기

[문제 원문](https://jungol.co.kr/problem/1516)

길이 200 이하의 문장을 공백으로 나누어 단어별 등장 횟수를 센다. 문장을 최대 30개까지 처리하며, 한 줄이 정확히 `END`이면 종료한다. 결과는 **단어의 ASCII 코드 순서**로 `단어 : 횟수` 형태로 출력한다.

### 문장마다 집계를 새로 시작한다

빈도순으로 정렬하는 것이 아니다. `map<string, int>`에 집계하면 키의 사전순으로 순회할 수 있다. 대소문자와 쉼표, 따옴표 등은 단어의 일부이므로 임의로 바꾸거나 제거하지 않는다.

구분자는 문제 조건대로 문자 `' '`만 사용한다. 줄 끝까지 단어가 이어지는 경우를 처리하려고 입력 문장 뒤에 공백 하나를 덧붙인다. 연속된 공백은 빈 단어를 만들지 않도록 건너뛴다.

```cpp showLineNumbers
void solve(){
    string line;
    while(getline(cin, line) && line != "END"){
        map<string, int> cnt;
        string word;
        line += ' ';
        each(c, line){
            if(c == ' '){
                if(!word.empty()) ++cnt[word];
                word.clear();
            }else word += c;
        }
        for(const auto& [s, count] : cnt)
            cout << s << " : " << count << '\n';
    }
}
```

`cnt`는 반복문 안에 있으므로 문장이 바뀔 때 이전 빈도가 남지 않는다. 원문 두 번째 예제의 `A C A A`는 `A : 3`, `C : 1`을 출력한다. 다음 문장 `2 2 2 2`는 별도로 집계하여 `2 : 4`를 출력한다.

한 문장의 길이를 $S$, 서로 다른 단어 수를 $U$라 하면 문자열 비교 비용까지 포함한 시간 상한은 $O(S\log(U+1))$, 공간은 $O(S)$이다. 입력을 읽는 데에도 $O(S)$가 든다.

## 7. 1661 — 미로 탈출 로봇

[문제 원문](https://jungol.co.kr/problem/1661)

가로 $X$, 세로 $Y$가 각각 최대 100인 미로에서 출발점부터 도착점까지의 최소 이동 시간을 구한다. 한 칸 이동하는 데 1초가 걸리며, `0`은 길, `1`은 벽이다.

### 좌표는 x, y이고 배열은 행, 열이다

입력 좌표는 예제에 따라 1부터 시작한다. 배열은 `a[y][x]`로 접근하므로, 코드에서는 `r = y - 1`, `c = x - 1`로 변환한다. 시작점의 거리는 0이다. 지나간 칸 수가 아니라 이동 횟수를 출력하기 때문이다.

모든 이동 비용이 같으므로 BFS에서 처음 방문한 거리가 최단 거리다.

```cpp showLineNumbers
void solve(){
    int w, h; ri(w, h);
    int sx, sy, ex, ey; ri(sx, sy, ex, ey);
    --sx; --sy; --ex; --ey;
    vs a(h); ri(a);
    vvi dist(h, vi(w, -1));
    queue<pii> q;
    dist[sy][sx] = 0;
    q.push({sy, sx});
    const int dr[] = {-1, 1, 0, 0};
    const int dc[] = {0, 0, -1, 1};
    while(!q.empty()){
        auto [r, c] = q.front(); q.pop();
        F0R(d, 4){
            int nr = r + dr[d], nc = c + dc[d];
            if(!bound(nr, nc, h, w) || a[nr][nc] != '0') continue;
            if(dist[nr][nc] != -1) continue;
            dist[nr][nc] = dist[r][c] + 1;
            q.push({nr, nc});
        }
    }
    po(dist[ey][ex]);
}
```

큐에 넣을 때 방문을 표시해야 같은 칸이 중복으로 들어가지 않는다. 원문 예제의 답은 `9`다. 원문은 도달 불가능한 경우의 출력값을 따로 명시하지 않으며, 이 코드는 그런 경우 초기값 `-1`을 출력하도록 두었다.

각 칸과 상하좌우 간선을 한 번씩 확인하므로 시간과 공간은 $O(XY)$이다.

## 8. 2115 — 스핑크스의 수수께끼

[문제 원문](https://jungol.co.kr/problem/2115)

$N\times N$ 동굴의 북서쪽에서 남동쪽까지 이동하는 경로 수를 구한다. $4\le N\le34$이며, 각 칸에는 0부터 9까지의 숫자가 공백 없이 주어진다. 현재 숫자가 $k$라면 **오른쪽으로 정확히 $k$칸 또는 아래로 정확히 $k$칸** 이동한다. 0인 칸에서는 더 움직이지 않는다.

### 오른쪽과 아래쪽으로만 경로 수를 전달한다

`dp[r][c]`를 `(r, c)`에 도착하는 경로 수로 정의한다. 출발점에는 빈 이동 경로 하나가 있으므로 `dp[0][0] = 1`이다. 현재 경로 수를 두 도착 후보에 더하면 된다.

오른쪽이나 아래로만 가므로 행 우선 순회에서 경로를 전달받는 칸은 아직 처리되지 않았다. 재귀 탐색이나 방문 배열이 필요하지 않다.

```cpp showLineNumbers
void solve(){
    int n; ri(n);
    vs a(n); ri(a);
    vvl dp(n, vl(n));
    dp[0][0] = 1;
    F0R(r, n) F0R(c, n){
        int k = a[r][c] - '0';
        if(k == 0 || (r == n - 1 && c == n - 1)) continue;
        if(r + k < n) dp[r + k][c] += dp[r][c];
        if(c + k < n) dp[r][c + k] += dp[r][c];
    }
    po(dp[n - 1][n - 1]);
}
```

0을 건너뛰지 않으면 현재 칸에 자기 자신의 경로 수를 더하는 잘못된 처리가 생긴다. 목적지도 더 확장하지 않는다.

원문은 답이 클 수 있다고 명시한다. 각 점프를 같은 방향의 단위 이동으로 펼치면 서로 다른 점프 경로는 서로 다른 단위 이동 경로가 된다. 따라서 경로 수는 최대 $\binom{66}{33}=7,219,428,434,016,265,740$이며 부호 있는 64비트 정수에 들어간다. `ll`로 저장하면 충분하고, `int`는 부족하다.

시간과 공간은 $O(N^2)$이다. 원문 예제의 답은 `3`이다.

## 9. 2326 — 조세퍼스 문제

[문제 원문](https://jungol.co.kr/problem/2326)

1번부터 $N$번까지 원형으로 앉은 사람 중 매 $M$번째 사람을 제거한다. 마지막 생존자만이 아니라 **제거되는 순서 전체**를 출력해야 한다. $1\le M\le N\le5,000$이다.

### 삭제할 사람의 순위를 계산한다

남은 사람을 벡터에 저장하고, 이번에 세기 시작할 위치를 0부터 세는 인덱스 `pos`로 둔다. 남은 인원이 `size`일 때 다음 제거 위치는 다음과 같다.

$$
pos=(pos+M-1)\bmod size
$$

삭제 후 뒤에 있던 사람이 같은 인덱스로 당겨지므로 `pos`를 추가로 증가시키지 않는다. 마지막 원소를 지운 경우도 다음 반복의 나머지 연산으로 처리된다.

```cpp showLineNumbers
void solve(){
    int n, m; ri(n, m);
    vi alive(n);
    iota(all(alive), 1);
    int pos = 0;
    bool first = true;
    cout << '<';
    while(!alive.empty()){
        pos = (pos + m - 1) % (int)alive.size();
        if(!first) cout << ", ";
        cout << alive[pos];
        first = false;
        alive.erase(alive.begin() + pos);
    }
    cout << ">\n";
}
```

벡터 삭제는 뒤쪽 원소를 이동시키므로 전체 시간은 $O(N^2)$, 공간은 $O(N)$이다. 이 제한에서는 간단한 구현으로 처리할 수 있다. 더 큰 입력에서는 순위 탐색을 지원하는 자료구조로 바꿀 수 있다.

출력의 꺾쇠와 쉼표 뒤 공백도 맞춘다. 원문 예제 `7 3`의 결과는 `<3, 6, 2, 7, 5, 1, 4>`다.

## 10. 2415 — 삼보나치 수열

[문제 원문](https://jungol.co.kr/problem/2415)

길이 $N$인 수열에서 정확히 한 항이 `-1`로 주어진다. 이를 양의 정수로 바꿔 모든 $i\ge3$에 대해 다음 식이 성립하게 해야 한다.

$$
A_i=A_{i-1}+A_{i-2}+A_{i-3}
$$

$4\le N\le20$이고, 주어진 나머지 항은 1 이상 1,000,000 이하이다. 올바른 수열을 만들 수 없으면 `-1`을 출력한다.

### 빈칸 하나를 복원한 뒤 다른 식도 확인한다

빈칸이 3번 이후에 있으면 앞의 세 항을 더해 값을 구한다. 처음 세 항 중 하나가 비었다면 `A[3] = A[0] + A[1] + A[2]`에서 나머지 두 값을 빼면 된다. $N\ge4$이므로 두 경우 모두 값을 결정할 식이 있다.

하지만 이 식 하나를 맞췄다고 수열 전체가 올바른 것은 아니다. 후보가 양수인지 확인하고, 모든 점화식을 다시 검사한다.

```cpp showLineNumbers
void solve(){
    int n; ri(n);
    vl a(n); ri(a);
    int missing = -1;
    F0R(i, n) if(a[i] == -1) missing = i;
    ll value;
    if(missing >= 3){
        value = a[missing - 1] + a[missing - 2] + a[missing - 3];
    }else{
        value = a[3];
        F0R(i, 3) if(i != missing) value -= a[i];
    }
    if(value <= 0){ po(-1); return; }
    a[missing] = value;
    FOR(i, 3, n){
        if(a[i] != a[i - 1] + a[i - 2] + a[i - 3]){
            po(-1);
            return;
        }
    }
    po(value);
}
```

예를 들어 원문 예제 `1 2 3 -1`은 `6`으로 복원된다. 설명용 반례 `1 2 3 -1 99`에서는 빈칸을 6으로 채울 수 있지만 다음 항은 11이어야 하므로 최종 답은 `-1`이다.

시간은 $O(N)$, 수열 저장 공간은 $O(N)$이다. 기존에 주어진 항들이 맞다는 보장은 없으므로 전체 검증을 생략하면 안 된다.

## 11. 1022 — Chess Metric

[문제 원문](https://jungol.co.kr/problem/1022)

Kingknight는 한 번에 킹의 8방향 이동 또는 나이트의 8가지 이동을 할 수 있다. $N\times N$ 보드에서 시작점부터 목표점까지 **정확히 $T$번 이동하는 경로 수**를 구한다. $3\le N\le100$, $1\le T\le50$이며 좌표는 0부터 시작한다.

### 같은 위치도 이동 횟수가 다르면 다른 상태다

최단 거리를 찾는 문제가 아니므로 목표에 일찍 도착했다고 종료하지 않는다. 목표를 지나 다시 돌아오는 경로도 정확히 $T$번 이동했다면 포함된다.

`dp[t][x][y]`를 정확히 $t$번 이동해 `(x, y)`에 도착하는 경우의 수로 정의한다. 매 단계에서 가능한 16개 목적지에 현재 값을 더한다. 이전 단계와 다음 단계의 배열을 분리해야 같은 단계에서 여러 번 이동하는 일이 없다.

```cpp showLineNumbers
void solve(){
    int n, sx, sy, ex, ey, moves;
    ri(n, sx, sy, ex, ey, moves);
    vector<pii> delta;
    for(int x = -1; x <= 1; ++x)
        for(int y = -1; y <= 1; ++y)
            if(x != 0 || y != 0) delta.push_back({x, y});
    for(int x = -2; x <= 2; ++x)
        for(int y = -2; y <= 2; ++y)
            if(abs(x) * abs(y) == 2) delta.push_back({x, y});
    const ll cap = 1LL << 31;
    vvl cur(n, vl(n));
    cur[sx][sy] = 1;
    F0R(step, moves){
        vvl nxt(n, vl(n));
        F0R(x, n) F0R(y, n){
            if(cur[x][y] == 0) continue;
            for(auto [dx, dy] : delta){
                int nx = x + dx, ny = y + dy;
                if(bound(nx, ny, n, n))
                    nxt[nx][ny] = min(cap, nxt[nx][ny] + cur[x][y]);
            }
        }
        cur.swap(nxt);
    }
    cout << cur[ex][ey] << '\n';
}
```

문제는 최종 답이 $2^{31}-1$ 이하라고 보장한다. 다만 **중간 단계의 다른 칸에 쌓이는 경로 수까지 같은 범위라고 보장하지는 않는다.** 예시 코드는 $2^{31}$ 이상의 값을 모두 `cap`으로 저장하는 포화 덧셈을 사용했다. 두 피연산자가 각각 `cap` 이하이므로 덧셈 자체도 `ll` 범위 안이다.

경로 수는 음수가 될 수 없고 전이는 덧셈뿐이다. 어떤 중간 상태에서 `cap`개 이상인 경로가 최종 목표까지 이어진다면 최종 답도 `cap` 이상이 된다. 따라서 최종 답이 그보다 작다는 보장 아래에서는 이 처리가 목표점의 정확한 답을 바꾸지 않는다.

격자는 정사각형이고 두 좌표 축의 이동 규칙이 대칭이므로 입력의 `(x, y)`를 그대로 배열의 두 인덱스로 사용해도 된다. 원문 예제 `3 0 0 1 0 1`의 답은 `1`이다.

칸마다 16개 이동을 확인하므로 시간은 $O(TN^2)$이고, 두 단계의 배열만 저장하므로 공간은 $O(N^2)$이다.

## 12. 1648 — 초월 공간 (HIPERCIJEVI)

[문제 원문](https://jungol.co.kr/problem/1648)

$N$개의 점과 $M$개의 초월 공간이 있다. 각 초월 공간에는 $K$개의 점이 속하며, 같은 공간 안의 점 사이에서는 자유롭게 이동할 수 있다. 1번에서 $N$번까지 가며 방문하는 최소 점의 수를 구하되 시작점과 도착점도 포함한다. 도달할 수 없으면 `-1`이다.

$N\le100,000$, $K,M\le1,000$이므로 같은 공간에 속한 점들을 모두 직접 연결하면 공간마다 $O(K^2)$개의 간선이 생긴다.

### 공간의 구성원을 처음 필요할 때 한 번만 펼친다

점마다 자신이 속한 공간 목록을 저장하고, 공간마다 구성원 목록을 저장한다. BFS 중 어떤 점에서 아직 사용하지 않은 공간을 발견하면 그 공간의 모든 점을 한 번에 확인한다.

처음 공간을 확장하는 점은 그 공간에 도달한 점 중 최단 거리를 갖는다. 따라서 구성원들은 현재 거리보다 1 큰 거리로 도달할 수 있다. 나중에 같은 공간을 다시 확장해도 더 짧은 경로를 만들 수 없으므로 `used`로 막는다.

```cpp showLineNumbers
void solve(){
    int n, k, m; ri(n, k, m);
    vvi members(m), groups(n + 1);
    F0R(g, m){
        members[g].resize(k);
        each(v, members[g]){
            ri(v);
            groups[v].push_back(g);
        }
    }
    vi dist(n + 1, -1), used(m);
    queue<int> q;
    dist[1] = 1;
    q.push(1);
    while(!q.empty()){
        int u = q.front(); q.pop();
        each(g, groups[u]){
            if(used[g]) continue;
            used[g] = 1;
            each(v, members[g]){
                if(dist[v] != -1) continue;
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }
    po(dist[n]);
}
```

이동 횟수만 세는 일반 BFS와 달리 시작점도 방문한 점 하나로 세므로 `dist[1] = 1`이다. `N = 1`이면 이동하지 않아도 답은 `1`이다.

점과 공간을 별도의 정점으로 연결하는 이분 그래프를 생각하면 같은 구조를 이해할 수 있다. 코드는 가상의 공간 정점을 큐에 넣는 대신 구성원 목록을 직접 확장한다.

소속 관계는 총 $MK$개이고 각 공간의 구성원을 한 번씩만 확인하므로 시간과 공간은 $O(N+M+MK)$이다. 원문 두 예제의 답은 각각 `4`, `3`이다.

## 13. 1660 — 2진수의 1의 개수

[문제 원문](https://jungol.co.kr/problem/1660)

자연수 $N$ 하나의 비트 수가 아니라 **1부터 $N$까지 모든 정수의 이진 표현에 등장하는 1의 총개수**를 구한다. $1\le N\le15,000$이다.

### 마지막 비트를 떼면 이미 계산한 수가 된다

`bits[i]`를 정수 `i`의 이진 표현에 있는 1의 개수로 정의한다. 오른쪽으로 한 비트 이동한 수의 결과에 마지막 비트가 1인지 더하면 된다.

$$
bits[i]=bits[i\gg1]+(i\mathbin{\&}1)
$$

`i >> 1`은 항상 `i`보다 작으므로 오름차순으로 계산하면 필요한 값이 이미 준비되어 있다.

```cpp showLineNumbers
void solve(){
    int n; ri(n);
    vi bits(n + 1);
    int res = 0;
    FOR(i, 1, n + 1){
        bits[i] = bits[i >> 1] + (i & 1);
        res += bits[i];
    }
    po(res);
}
```

이 범위에서 정수 하나는 최대 14비트이므로 합은 $14N$ 이하이며 `int`로 충분하다. 원문 예제 `N = 5`에서는 `1`, `10`, `11`, `100`, `101`의 1 개수를 더해 $1+1+2+1+2=7$을 얻는다.

시간과 공간은 $O(N)$이다. 각 수를 독립적으로 이진수 문자열로 바꾸지 않아도 된다.

## 14. 1685 — 숫자삼각형

[문제 원문](https://jungol.co.kr/problem/1685)

맨 위에서 시작해 바로 아래층의 대각선 왼쪽 또는 오른쪽으로 내려갈 때 선택한 수의 합이 최대가 되는 경로를 구한다. 삼각형의 크기는 최대 100이고 각 값은 0 이상 99 이하이다.

### 자식의 최적값을 알고 있으면 현재 최적값도 구할 수 있다

`a[r][c]`를 그 칸에서 시작해 맨 아래까지 내려가는 최대 합으로 바꾼다. 마지막 행은 더 내려갈 곳이 없으므로 원래 값이 그대로 답이다. 위쪽 행은 두 자식 중 큰 값을 현재 값에 더한다.

$$
a[r][c]\gets a[r][c]+\max(a[r+1][c],a[r+1][c+1])
$$

```cpp showLineNumbers
void solve(){
    int n; ri(n);
    vvi a(n);
    F0R(r, n){
        a[r].resize(r + 1);
        ri(a[r]);
    }
    for(int r = n - 2; r >= 0; --r)
        for(int c = 0; c <= r; ++c)
            a[r][c] += max(a[r + 1][c], a[r + 1][c + 1]);
    po(a[0][0]);
}
```

현재 눈에 보이는 두 자식 중 숫자가 큰 쪽을 바로 선택하면 이후 경로를 놓칠 수 있다. DP에서는 **그 자식부터 끝까지의 최대 합**을 비교하므로 이후 선택까지 반영된다.

`N = 1`이면 갱신 반복문을 실행하지 않고 입력값 자체를 출력한다. 최대 경로 합은 $100\times99=9,900$이므로 `int`로 충분하다. 원문 예제의 답은 `30`이다.

시간과 삼각형 저장 공간은 $O(N^2)$이며, 입력 배열을 그대로 갱신하므로 추가 계산 공간은 $O(1)$이다.

## 답을 세는 기준과 상태를 먼저 정하기

미로 탈출 로봇은 **이동 시간**, 초월 공간은 **시작점까지 포함한 방문 점 수**, Chess Metric은 **정확히 정해진 횟수만큼 이동한 경로 수**를 구한다. 비슷하게 이동하는 문제라도 시작값과 상태가 달라진다.

스핑크스의 수수께끼와 숫자삼각형은 이동 방향에 따라 계산 순서가 정해진다. 삼보나치 수열은 후보 하나를 구한 뒤 전체 조건을 확인해야 한다. 단어 세기와 비밀번호는 종료 표식, 집계 범위, 출력 순서까지 문제의 일부다.

풀이를 정리하며 먼저 적어 둘 것은 **무엇을 세는지, 어떤 정보를 상태로 저장하는지, 그 상태를 어떤 순서로 갱신하는지**다. 이 세 가지가 명확해지면 초기값과 경계 처리도 함께 정리된다.
