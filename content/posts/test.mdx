## 섹션 제목(H2)
일반 본문은 아무 옵션 없이 쓰면 됩니다. **볼드**, _이탤릭_, `인라인 코드`도 그대로 스타일이 붙어요.

> 인용문은 이렇게. 왼쪽 보더, 흐린 텍스트로 렌더링됩니다.

### 리스트
- 항목 하나
- 항목 둘
- 항목 셋

### 코드 블록
언어 자동 감지(rehype-highlight 사용 시 언어를 안 적어도 하이라이트):
```
function greet(name) {
  return `hello ${name}`
}
```

언어를 지정해서 더 정확히:
```ts
export const add = (a: number, b: number) => a + b
```

cpp 테스트
```cpp
#include <bits/stdc++.h>

using namespace std;

int main(){
    cout << "Hello World!";
    return 0;
}
```
